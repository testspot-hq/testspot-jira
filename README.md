# TestSpot for Jira

Панель TestSpot в задаче Jira: связанные тест-кейсы, прогоны и дефекты.
Панель предназначена для просмотра; прогоны создаются в TestSpot.

## Jira Data Center / Server

Скачайте комплект из [Releases](https://github.com/testspot-hq/testspot-jira/releases/latest):

- `testspot-jira-panel-0.1.1-dc.zip` — интерфейс панели v0.1.1, JAR 0.1.0, инструкция и контрольные суммы.
- `testspot-jira-panel-0.1.0.jar` — плагин для загрузки в Jira; он не изменился относительно v0.1.0.
- `INSTALL.md` — установка и обновление обеих сторон.
- `SHA256SUMS` — SHA-256 файлов релиза.

**В v0.1.1 убрана кнопка «Создать прогон».** Для существующей установки обновите
интерфейс `/embed/jira/` на сервере TestSpot файлами из `panel/` в ZIP.
Переустановка JAR не требуется и сама по себе не обновляет интерфейс.
Пошаговые действия и вариант с Docker описаны в [инструкции](INSTALL.md).

При первой установке загрузите JAR через **Administration → Manage apps → Upload app**,
затем настройте адрес TestSpot и общий секрет по инструкции.
Каждый пользователь подключает свою учётную запись TestSpot.

## Jira Cloud

Cloud использует отдельное приложение **Atlassian Forge**. JAR и ZIP этого репозитория
предназначены только для Data Center / Server. Публикация GitHub-релиза не обновляет
установку Cloud: она обновляется отдельно через Forge.

## Какие прогоны отображаются

Панель показывает прогон, связанный с задачей Jira напрямую, либо содержащий результат,
связанный с этой задачей. Связь задачи с тест-кейсом не добавляет автоматически все прогоны кейса.

[TestSpot CLI](https://github.com/testspot-hq/testspot-cli) — загрузка результатов автотестов из CI.

## Метаданные сборки

Метаданные сборки нормализованы на аккаунт testspothq; Java-классы и поведение плагина не изменены. Контрольные суммы JAR и ZIP пересчитаны.
